# SwimQuest — Full Platform Design Pack v2.0
Status: product/design specification only. No code has been implemented by this package.

## Product scope
This update expands SwimQuest from Route 01 gameplay into a complete platform foundation:
1. Account registration and authentication
2. User profile
3. Tournament creation and management
4. Team creation, invitations and membership
5. Tournament discovery and joining
6. Route 01 start selection, with Lý Sơn as the shared finish
7. Verified swim activity submission and progress
8. Leaderboards, badges and completion
9. Organizer/admin controls, analytics, privacy and safety

## Files
- `product-GDD.md`: end-to-end product scope and user journeys
- `account-and-roles.md`: accounts, authentication, roles and permissions
- `tournaments-and-teams.md`: tournament lifecycle, teams and membership
- `route01-rules-and-scoring.md`: approved route rules and scoring
